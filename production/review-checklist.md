# Manga QA Checklist

## Narrative

- [ ] Character motivations are coherent
- [ ] Dialogue is natural
- [ ] Chronology is correct
- [ ] Internal thoughts are clearly distinguished

## Visual

- [ ] Correct faces and hairstyles
- [ ] Correct relative heights
- [ ] Correct body proportions
- [ ] Clothing matches the scene
- [ ] Accessories remain consistent
- [ ] Lighting and backgrounds are coherent
- [ ] Hands and anatomy are correct

## Page

- [ ] Panel order is readable
- [ ] Dialogue fits intended space
- [ ] Lettering is legible
- [ ] Page dimensions match the standard

## Publication

- [ ] Content is approved
- [ ] No private source material included
- [ ] Chapter continuity updated
