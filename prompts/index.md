## Using the Prompts

- [Reference workflow and current images](reference-workflow.md)
- [Manga panel and correction templates](scenes/manga-panel-template.md)

Each file has source links and a complete copyable prompt. Attach fictional
character references when available. Current profiles take precedence over
superseded draft ages, names, and heights. Resolve conflicts with approved
artwork before replacing it.

The proposed 3:2 reference-sheet composition is a design-study layout, not an
approved manga page specification. Exact outfit combinations and unselected
details are proposals. No generated result becomes canon automatically.

Keep reusable character facts in the profiles and drawing instructions here.
When a profile changes, update the corresponding prompt and record the revision.
For future prompt variants, use separate descriptive files such as
`character-name-portrait.md` or `character-name-scene-reference.md`.

## Scope

This library contains character-sheet prompts plus reusable panel/correction
templates. The six supplied cards are registered for future reuse. No new story
scene, family group art, or relationship event has been created.
