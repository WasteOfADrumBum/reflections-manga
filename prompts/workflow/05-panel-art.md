# Produce an Authorized Art Batch

Status: Reusable prompt template, not authorization to execute every stage now.
Updated: 2026-11-12.
Replace bracketed fields; skip optional fields you do not know.

```text
Work in the Reflections Manga project. Keep relevant project records updated.

Produce draft artwork for Reflections [CHAPTER ID], [PAGE/PANEL RANGE], using
its approved script, storyboard, and selected page standards.

Read the current profiles, reference notes, and continuity. Inspect and attach
the actual saved character images to each generation request, with an explicit
image-to-character mapping. Add relevant approved setting/outfit/previous-panel
references. Use prompts/scenes/manga-panel-template.md. Do not redesign the cast
or change approved dialogue, story beats, page layout, or outfits.

Generate individual panel art with reserved lettering space and no baked-in
dialogue. Review each result for identity, proportions, scene geography,
clothing, rings, props, and lighting. Correct execution errors within this
batch's scope and retain versioned outputs. Keep the original sheets as anchors.

Save actual images under this chapter's art directory and generation prompts
and reference mappings under generation. If output transfer fails, report the
specific blocker without claiming a local save. Update continuity and handoff.
Stop at the requested batch, show reviewable results, and do not mark them
approved unless approval is given. Do not generate the whole series.
```
